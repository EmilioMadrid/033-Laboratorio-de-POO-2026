# 1. ¿Qué diferencia hay entre JDK, JRE y JVM? ¿Por qué instalamos el JDK?
    * La Java Virtual Machine lee el código ya compilado y lo traduce a instrucciones que la computadora pueda entender.
    * Java Runtime Environment es el paquete mínimo para que un usuario pueda ejecutar aplicaciones de Java. No puedes crear programas con el.
    * Java Development Kit es el paquete que usa el programador. Contiene el JRE y herramientas de desarrollo como el compilador.
# 2. ¿Por qué Java es considerado «write once, run anywhere»? Explica con tus propias palabras.
    Porque, para el curso de POO es necesario compilar y depurar código. Sin el JDK, NetBeans no tendría como transformar los archivos .java en programas ejecutables.
# 3. ¿Qué hace exactamente =System.out.println()=? ¿Qué clase y método estás usando?
    * System: Es una clase de Java que proporciona acceso a la entrada, salida y errores del sistema.
    * out: Es un objeto que representa el flujo de salida.
    * println(): Es el método que pertenece al objeto out. Su función es imprimir el texto entre paréntesis y, al terminar, agregar automáticamente un salto de línea.
